## 发布门槛（Definition of Done）

任何声称“一键完成”的项目都必须通过：预检兼容、幂等安装、配置校验、服务正常启动、端口连通、凭据不泄露、故障阻断、升级策略、恢复演练和自动化测试。只有下载或二进制存在，不能标记为“部署成功”。

## v0.1.1 Alpha 密码登录增强

- 新增 SSH 密码登录（仅服务进程内存保存、重启重新输入）和既有密钥登录切换。
- 主机指纹扫描支持 Ed25519/ECDSA/RSA，仍需独立核对。
- 真实 VPS 与 Docker 运行需要人工验收，密码认证错误不会尝试更改 sshd 配置。

## v0.1.2 Alpha Windows SSH 指纹修复

- 通过 Paramiko SSH 握手直接读取主机公钥，不再依赖 `ssh-keyscan` 和本机 `ssh-keygen` 可执行文件；Windows、Linux 统一逻辑。
- 提供连接超时、端口拒绝、域名解析错误、SSH 握手失败等分类信息，并在面板提供 PowerShell 端口诊断命令。
- 已信任密钥由 Paramiko `HostKeys` 检查，仍不允许未经人工核对的新密钥覆盖旧记录。
- 新增多平台测试用例并保持原有密码认证和审批安全检查；尚未在真实 VPS 上验收。
