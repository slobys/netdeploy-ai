① 添加服务器→② SSH 指纹→③ 连接检测→④ 网络端口（可跳过）→⑤ 选择软件
先备份测试 VPS

本版会使用已审核的远程高权限安装脚本；请先使用临时、可快照或可重装的 Debian / Ubuntu VPS。

第 1 步：添加 VPS

  1. 打开 NetDeploy 面板，点击右上角 添加 VPS。
  2. 输入易识别的名称、服务器公网 IPv4、SSH 端口（默认 22）、SSH 用户（自动安装目前要求 root）。
  3. 如果已有域名需要签 HTTPS 证书，再填写 HTTPS 证书域名；没有域名可以留空，由 3X-UI 安装方案按公网 IP 选择证书类型。
  4. 选择 SSH 密码或私钥登录，保存后继续下一步。

第 2 步：SSH 主机指纹

面板会扫描 SSH 主机公钥并显示 SHA-256 指纹。请在云厂商独立可信控制台查看服务器公钥指纹，两边一致后再点击确认；不要只凭 NetDeploy 自己显示的结果就信任。

# 在 VPS 云厂商的原生终端中运行（示例为 ED25519）：
ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub -E sha256

若服务器使用 RSA / ECDSA，按提示选择对应的 /etc/ssh/ssh_host_*.pub。曾经信任且未变化的指纹可直接继续；VPS 重装后出现变化，必须重新独立核对。

第 3 步：测试 SSH 连接与系统

点击环境检测。系统会确认发行版、CPU、root 权限、磁盘、systemd、端口占用和已安装组件；检测失败会在当前步骤说明原因，无需返回主页重新添加。

第 4 步：端口与防火墙（可跳过）

可以先只查看 UFW 状态。需要开放端口时点击 ＋ 添加端口，逐条填写 TCP/UDP，最后点 一次放行全部端口。如果你还没确定要开放哪些端口，点击 跳过此步，下一步：选择软件 即可。

阿里云、腾讯云、Google Cloud 和 AWS 还需要在对应云控制台检查入站安全组；本机 UFW 规则不等于公网自动放行。详见 端口与防火墙。

第 5 步：选择软件

从项目卡片选择 3X-UI、S-UI、sing-box 或 wg-easy。系统会识别现有安装并生成计划，先展示兼容性要求、具体命令和风险，再由管理员审核批准。Hysteria2 当前仍为引导方案，不能当作完整自动安装。

任务执行完成后

到 最近任务 / 部署任务查看状态与分步骤日志。对于支持登录信息展示的 3X-UI、S-UI，可点击 查看面板信息按需读取 VPS 上的初始凭据。S-UI 默认仅本地监听，需要按提示使用 SSH 隧道访问。

如果任务状态是失败或部分完成，先对照 故障排查，不要在原 VPS 上盲目重复安装。
