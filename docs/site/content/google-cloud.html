谷歌云一键修改 root 密码并开启 SSH 登录

先在 Google Cloud 虚拟机实例中打开浏览器 SSH 或串口终端，再复制下面四行执行。将第一行的 YOUR_NEW_ROOT_PASSWORD 替换成你自己设置的强密码，不要直接使用示例文字或网上公开的固定密码。

echo 'root:YOUR_NEW_ROOT_PASSWORD' | sudo chpasswd
sudo sed -i 's/^#\?PermitRootLogin.*/PermitRootLogin yes/g' /etc/ssh/sshd_config
sudo sed -i 's/^#\?PasswordAuthentication.*/PasswordAuthentication yes/g' /etc/ssh/sshd_config
sudo reboot

命令依次修改 root 密码、允许 root 登录、开启 SSH 密码认证，最后重启 VPS。第一行的 chpasswd 后面不要再加 root，因为用户名已经包含在输入的 root:密码 中。

使用提醒

启用 root 密码 SSH 有被暴力破解的风险，建议先备份实例，并在 Google Cloud 防火墙将 SSH 端口的来源限制为自己的管理 IP。命令会在 Shell 历史中留下密码，执行后应清理包含密码的历史记录；最后一行会立即重启并断开当前连接，请保留云控制台的恢复方式。

改完密码仍无法登录？

如果开启了 Google Cloud OS Login / IAM，或 SSH 的 sshd_config.d 文件覆盖了主配置，这四行命令不一定能启用 root 密码登录。需要检查实例的实际 SSH 策略，不要为此关闭全部安全设置。

谷歌云防火墙

可在 Google Cloud 防火墙规则中确认实例的 SSH 入站规则，只允许可信的管理来源 IP。
