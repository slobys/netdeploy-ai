谷歌云特别注意：不要把 root 固定密码放到公开命令里

你可能在网络教程看到 echo root:某个固定密码 | sudo chpasswd，再把 SSH 的 PermitRootLogin、PasswordAuthentication 改为 yes 后重启。这会暴露密码并扩大公网 SSH 攻击面；本文提供更安全的交互式替代方法，绝不公开预设 root 密码。

谷歌云的推荐 SSH 管理方式

Google Cloud Compute Engine 公开 Linux 镜像一般不允许 root 密码 SSH 登录。官方优先推荐通过 OS Login / SSH 密钥 登录普通账户，再使用 sudo 执行管理操作，而不是开放 root 密码登录。Google Cloud 官方 root SSH 说明 ↗。

先进入 Google Cloud Compute Engine 实例，选择实例、项目与区域，使用浏览器里的 SSH 按钮连接。若当前实例启用了 OS Login 或被组织策略约束，应继续使用 IAM 管理的密钥，不要通过修改单个文件绕过组织要求。

快捷修改 root 本地密码（推荐）

在谷歌云实例的原生 SSH / 串口控制台执行一条命令：

sudo passwd root

系统会要求你输入新密码两次。终端不会回显密码，命令历史不会记录明文。此操作仅修改 root 本地密码，不保证允许从外网用 root 密码登录 SSH，也不会自动重启。

NetDeploy 交互式脚本（可复制）

也可以下载 NetDeploy 仓库提供的帮助脚本并执行。初次使用请先浏览脚本内容；它默认只修改本地 root 密码，不变更 SSH 配置。

curl -fsSLo /tmp/netdeploy-gcp-root-setup.sh https://raw.githubusercontent.com/slobys/netdeploy-ai/main/scripts/gcp-root-setup.sh
less /tmp/netdeploy-gcp-root-setup.sh
sudo bash /tmp/netdeploy-gcp-root-setup.sh --password-only
更改密码不是重启服务器

脚本使用 passwd root 交互输入密码，默认不修改 SSH 登录方式，不会执行 reboot，避免使当前连接突然中断。

确实需要 root 密码 SSH？仅限受控测试

高风险操作，默认关闭

仅当你明确需要 NetDeploy 的 root 密码认证、已在 Google Cloud VPC 防火墙将 SSH TCP 22 入站来源限制为自己的管理公网 IP /32、已保存实例快照，并拥有云厂商控制台恢复通道时，才考虑开启。官方建议仍是密钥与 sudo。

若目标是 Debian / Ubuntu、未启用 OS Login，且你明确理解风险，可以在上述脚本下载并审查后使用可选模式：

sudo bash /tmp/netdeploy-gcp-root-setup.sh --enable-root-password-ssh

脚本会要求输入指定的完整风险确认语句，交互设置 root 密码，备份原 sshd_config，写入独立配置文件，并检查 sshd -t 与有效配置；成功后只重新加载 SSH 服务，不会重启整台 VPS。检测到 Google Cloud OS Login 为启用状态时会拒绝继续。此模式仍不保证云平台组织策略允许直接 root SSH。

保持原来的云控制台窗口打开。在另一台电脑、另一个终端测试 root SSH 是否能成功；确认前不要断开原会话。如果失败，按脚本提示从云终端撤销新增配置并重新加载 SSH。不要为了测试而向 0.0.0.0/0 公开 22 端口。

修改之后怎样验证？

  1. 在谷歌云实例终端运行 sudo /usr/sbin/sshd -t，确认配置语法有效。
  2. 运行 sudo /usr/sbin/sshd -T 检查生效的认证策略；不要仅以文本文件的字面设置判断。
  3. 在 Windows PowerShell 运行 Test-NetConnection YOUR_VPS_IP -Port 22；能连接仅证明端口可达，不代表认证成功。
  4. 通过另一终端验证登录，再在 NetDeploy 完成 SSH 主机指纹独立核验。

为什么改了密码仍然不能登录？

可能是 Google Cloud OS Login / IAM 规则生效、云防火墙未允许你的来源 IP、sshd 有其他配置优先级、root 账户策略、PAM 或实例没有公网 IPv4。优先检查 Google Cloud SSH 最佳实践 与 IAP SSH 隧道；不要为了“能登录”而关闭所有安全设置。

谷歌云 VPC 防火墙

打开 Google Cloud 防火墙规则，选择实例关联的 VPC / 网络、匹配的目标标签或服务账号、协议与端口。仅向指定源地址开放必要入站流量；修改 VPS 本地 UFW 不等于同时修改云端规则。
