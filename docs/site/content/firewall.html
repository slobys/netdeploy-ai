两个独立的防火墙

NetDeploy 当前能操作 VPS 内部的 UFW；阿里云、腾讯云、Google Cloud、AWS 等云平台还有一层独立的安全组 / VPC 防火墙。两边都要允许目标流量，公网访问才可能成功。

如何一次添加多个端口

  1. 打开 添加 VPS → 第 4 步：端口与防火墙，或者已有服务器的 网络端口页面。
  2. 点击 ＋ 添加端口，逐行输入 1–65535 的端口并选择 TCP / UDP。
  3. 最多一次提交 20 项。8443/TCP 和 8443/UDP 是不同规则，完全重复的端口/协议组合会提示错误。
  4. 点击 一次放行全部端口，查看每项成功、失败或“未修改”状态。出现部分失败时只重试失败项。

云厂商安全组快捷入口

阿里云 ECS 安全组 ↗进入云控制台后选择对应地域、实例与安全组。 腾讯云 CVM 安全组 ↗找到与目标实例关联的安全组，检查入站规则。 Google Cloud VPC 防火墙 ↗检查网络、目标实例标签 / 服务账号与允许的来源网段。 AWS EC2 Security Groups ↗选择正确 Region，在 EC2 的安全组里设置入站规则。

以上是官方入口，不代表点击后规则已经自动创建。建议 SSH 与管理面板只允许固定的管理 IP（例如 203.0.113.10/32，仅为文档示例地址）。

UFW 未启用代表什么？

如果系统没有安装 UFW 或显示 inactive，本机不需要重复添加 UFW 规则；但云平台安全组、其他防火墙组件、服务监听以及运营商网络仍可能阻断访问。不要把“软件安装成功”误认为“公网端口已经开放”。

关闭 UFW 会怎样？

不推荐为了省事关闭全部防火墙

这会失去 VPS 本机的 UFW 端口过滤保护，并可能暴露 SSH 或管理面板。NetDeploy 将此操作置于高级区域，明确确认风险后才执行，正常安装过程不会自动关闭 UFW。

更合适的方案是精确开放所需端口，再到云平台安全组设置限制来源。若暂时不确定，直接跳过第 4 步，等软件安装完成后再检查。
