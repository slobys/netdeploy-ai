首页与项目中心：紧凑项目卡片

v{{version}} 起，首页「精选部署项目」与左侧「项目中心」都使用自适应紧凑卡片。图标、名称、功能简介、安装状态和部署按钮集中排列，减少无意义留白；宽屏下当前 5 个项目可同排显示，窄屏会自动换列。项目中心只保留一个页面标题及项目数量，避免重复出现「精选部署项目」和「查看全部项目」。全部部署/查看方案操作保持不变，兼容所有主题颜色、明暗模式和三档阅读字号。

NetDeploy 的实际工作流程

添加 VPS→核对指纹→环境检测→可选网络配置→部署软件

安装不是“点一下就不经确认地运行远程命令”。面板会先检查系统与冲突，再生成可审核的固定脚本；管理员明确批准之后才执行。日志和错误状态会显示在任务页面。

个性化外观与主题

NetDeploy 控制台右上角新增 ◐ 主题：可以切换 明亮 / 暗黑 / 跟随系统 三种外观，并选择经典蓝、极光紫、海洋青、翡翠绿、玫瑰粉、暖日橙六种主题色。改变会立即应用到仪表盘、服务器控制台、配置弹窗与表单，无需重新加载或连接 VPS。

默认使用原来的经典蓝 · 暗黑主题。配置仅保存在本机浏览器的主题偏好中，不写入 NetDeploy 数据库，也不会上传 SSH 凭据或账号信息；下一次打开相同浏览器时自动恢复。跟随系统模式会响应 Windows 系统深浅模式变化。

文字看不清？在同一个「◐ 主题」菜单里找到阅读字号，可选「标准 / 舒适 / 大字」。v{{version}} 默认使用舒适字号：导航、项目介绍、统计卡片、按钮、SSH 检测和各类表单的字号、行距都已统一放大。选择大字还会适当增高卡片、让长文字换行，避免弹窗挤压。字号同样会在当前浏览器自动记住；不影响服务器、部署任务或 SSH 密码。
