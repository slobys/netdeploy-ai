这是 Alpha 测试版

当前以 Windows 11 本机面板、Debian / Ubuntu 测试 VPS 为主。先使用可重置服务器试用，不要直接在重要生产业务上执行未经验证的部署任务。

第一次使用从这里开始

01 · 安装 NetDeploy准备 Git、Python，Windows 一条命令启动。以后可保留数据直接更新。 02 · 五步添加与部署服务器信息 → SSH 指纹 → 系统检测 → 可选防火墙 → 选择项目。 03 · Google Cloud 谷歌云从云控制台建立安全 SSH；交互修改 root 密码与检查登录设置。 04 · 解决常见问题打不开页面、指纹变化、SSH 超时、HTTPS 证书失败时怎么办。

能帮你做什么？

🖥 服务器与 SSH 管理保存服务器记录、检查连接、核对主机指纹、恢复重装后的信任关系。 🔐 TCP / UDP 端口最多批量放行 20 条 UFW 规则，也可以打开云厂商安全组页面。 ⚙️ 软件部署3X-UI、S-UI、sing-box、wg-easy 的安装路径与验证步骤。 🛡 数据与安全了解本机运行、审批机制、密钥保管方式和当前不支持的情况。

NetDeploy 的实际工作流程

添加 VPS→核对指纹→环境检测→可选网络配置→部署软件

安装不是“点一下就不经确认地运行远程命令”。面板会先检查系统与冲突，再生成可审核的固定脚本；管理员明确批准之后才执行。日志和错误状态会显示在任务页面。

项目与反馈

源代码、测试与提交记录托管在 GitHub · slobys/netdeploy-ai。遇到问题可到 Issues 提交系统版本、软件版本和脱敏错误日志，不要上传私钥、密码、令牌或真实凭据。
