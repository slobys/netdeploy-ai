运行概览、项目中心与部署任务

首页的运行概览下方显示每台 VPS 的 SSH 连通性、CPU、内存和根磁盘占用。面板可见时大约每 25 秒发起一轮采样，使用已核验指纹的 SSH 连接读取数据。卡片背景随已采集指标中最高的一项变色，低于 70% 为浅绿，达到 70% 为琥珀色，达到 85% 为红色。没有可用读数时，卡片使用中性色，指标显示为「—」。

项目及排序可在左侧「项目中心」查看。部署任务可按状态筛选，每台 VPS 的控制台也保留自己的任务历史。任务详情中的「安装日志」默认折叠，点击即可查看。

Dockge Apps · 二开应用中心

v{{version}} 起，「项目中心」的 Dockge 项目改为从 slobys/dockge-apps 固定源码构建，支持 Docker Compose 管理与 Nginx Proxy Manager、IT-Tools、MyIP 应用中心。原版实例不会自动迁移。新安装默认生成 VPS 公网 IP + 随机或自定义端口的管理链接，风险在部署审批时提示；干净 VPS 缺少 Docker/Compose 时，可在同一次审批内自动准备依赖。查看部署与数据保护说明。

3X-UI / S-UI 支持 NPM 统一 HTTPS

安装面板时可选择「不申请证书，交给 NPM 反向代理」。这样跳过面板自己的 Certbot 和 TCP 80 ACME 验证；3X-UI 会在审批后提供可直接打开的公网 IP:端口 HTTP 地址，S-UI 仍仅本机监听，NPM 统一为各个域名申请 SSL。查看 NPM 配置和 Docker 网络说明。

NetDeploy 的实际工作流程

添加 VPS→核对指纹→环境检测→可选网络配置→部署软件

安装不是“点一下就不经确认地运行远程命令”。面板会先检查系统与冲突，再生成可审核的固定脚本；管理员明确批准之后才执行。日志和错误状态会显示在任务页面。

个性化外观与主题

NetDeploy 控制台右上角新增 ◐ 主题：可以切换 明亮 / 暗黑 / 跟随系统 三种外观，并选择经典蓝、极光紫、海洋青、翡翠绿、玫瑰粉、暖日橙六种主题色。改变会立即应用到仪表盘、服务器控制台、配置弹窗与表单，无需重新加载或连接 VPS。

默认使用原来的经典蓝 · 暗黑主题。配置仅保存在本机浏览器的主题偏好中，不写入 NetDeploy 数据库，也不会上传 SSH 凭据或账号信息；下一次打开相同浏览器时自动恢复。跟随系统模式会响应 Windows 系统深浅模式变化。

文字看不清？在同一个「◐ 主题」菜单里找到阅读字号，可选「标准 / 舒适 / 大字」。v{{version}} 默认使用舒适字号：导航、项目介绍、统计卡片、按钮、SSH 检测和各类表单的字号、行距都已统一放大。选择大字还会适当增高卡片、让长文字换行，避免弹窗挤压。字号同样会在当前浏览器自动记住；不影响服务器、部署任务或 SSH 密码。
