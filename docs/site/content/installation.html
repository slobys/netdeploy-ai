推荐方式：Windows 11 本机运行

NetDeploy 是在你自己的电脑上打开的 Web 管理面板，默认访问地址为 http://127.0.0.1:8787。你的 VPS 不需要安装 NetDeploy 本体。

安装前准备

  • 电脑：Windows 11，能访问 GitHub。
  • 安装 Git for Windows 和 Python 3.12 或以上版本，需有 Windows py 启动器。
  • 预备一台 Debian / Ubuntu 测试 VPS，能够通过云厂商控制台独立查看 SSH 指纹。

一条命令安装与启动

打开 Windows PowerShell，复制以下整行。脚本会在桌面创建或复用 netdeploy-ai-git 目录，检查 GitHub 来源、更新代码、安装依赖，再启动面板。

$repo=Join-Path ([Environment]::GetFolderPath('Desktop')) 'netdeploy-ai-git'; if(-not(Test-Path $repo)){git clone https://github.com/slobys/netdeploy-ai.git $repo; if($LASTEXITCODE -ne 0){throw 'Git clone failed'}}; $start=Join-Path $repo 'scripts\QuickStart-Windows.ps1'; powershell.exe -NoProfile -ExecutionPolicy Bypass -File $start

启动成功后，浏览器通常会自动打开 http://127.0.0.1:8787。桌面出现的 netdeploy-ai-git 是本机工作目录，不是 VPS 数据目录。

首次启动不需要手填面板令牌

Windows 单机快捷启动可自动创建本机管理员令牌并启用环回地址自动登录；VPS SSH 密码仍必须单独提供。

以后怎么重新打开？

  1. 进入桌面 netdeploy-ai-git。
  2. 双击 QuickStart-NetDeploy.bat，即可检查更新并打开面板。
  3. 若提示 8787 已被占用，先到旧的 PowerShell 服务窗口按 Ctrl+C 停止，再重新启动；不要用两个进程同时操作同一数据库。

更新软件，不丢原有数据

推荐先停止旧服务，再双击 QuickStart-NetDeploy.bat；也可运行 Update-NetDeploy.bat 更新后用 Start-NetDeploy.bat 启动。更新器会保留原有的本地配置、任务数据库、可信 SSH 主机密钥，并对本地数据执行备份。

更新后在浏览器按 Ctrl+F5 强制刷新。右上角版本号与 /api/health 返回的版本应一致；否则可能仍在运行旧进程。

Docker / NAS 用户

仓库提供 compose.yaml，适用于懂得管理 Docker、目录权限与管理员令牌的用户。此模式默认只映射宿主机 127.0.0.1:8787，不应直接暴露公网。请按 README 的 Docker 操作说明 配置管理员密钥并使用 SSH 隧道访问。
