推荐方式：Windows 11 本机运行

NetDeploy 是在你自己的电脑上打开的 Web 管理面板，默认访问地址为 http://127.0.0.1:8787。你的 VPS 不需要安装 NetDeploy 本体。

Windows 安装包

从 GitHub Releases 下载 NetDeployAI-0.3.42-Setup-x64.exe。支持 Windows 10/11 x64，安装后从桌面或开始菜单直接打开独立客户端。Python、SSH 客户端与 Codex SDK 已包含在安装包中。缺少 WebView2 时，安装程序自动联网安装微软运行组件。

程序默认后台运行。需要退出时，在开始菜单选择退出 NetDeploy AI。用户数据位于 %LOCALAPPDATA%\NetDeployAI\desktop，覆盖安装和卸载均保留。首次使用 Codex 请登录自己的 ChatGPT 账号。安装包尚未配置代码签名，Windows 可能显示未知发布者提示。源码版用户可继续使用下面的 QuickStart。

源码运行准备

Windows 客户端每次打开会自动检查更新；点击右上角版本号也可手动检查。发现新版后点击下载并更新，客户端会下载并校验安装包、备份本机数据、覆盖安装并自动重启。更新保留 VPS、任务、ChatGPT 登录和窗口大小；执行中的部署需先结束。网络失败时可重试，也可以继续从 GitHub 手动下载安装包。旧版客户端需要先手动覆盖安装一次以启用在线更新。

  • 电脑：Windows 11，能访问 GitHub。
  • 安装 Git for Windows 和 Python 3.12 或以上版本，需有 Windows py 启动器。
  • 预备一台 Debian / Ubuntu 测试 VPS，能够通过云厂商控制台独立查看 SSH 指纹。

一条命令安装与启动

打开 Windows PowerShell，复制以下整行。脚本会在桌面创建或复用 netdeploy-ai-git 目录，检查 GitHub 来源、更新代码、安装依赖，再启动面板。

$repo=Join-Path ([Environment]::GetFolderPath('Desktop')) 'netdeploy-ai-git'; if(-not(Test-Path $repo)){git clone https://github.com/slobys/netdeploy-ai.git $repo; if($LASTEXITCODE -ne 0){throw 'Git clone failed'}}; $start=Join-Path $repo 'scripts\QuickStart-Windows.ps1'; powershell.exe -NoProfile -ExecutionPolicy Bypass -File $start

启动成功后，浏览器通常会自动打开 http://127.0.0.1:8787。桌面出现的 netdeploy-ai-git 是本机工作目录，不是 VPS 数据目录。

首次启动不需要手填面板令牌

Windows 单机快捷启动可自动创建本机管理员令牌并启用环回地址自动登录；VPS SSH 密码仍必须单独提供。

以后怎么重新打开？

  1. 进入桌面 netdeploy-ai-git。
  2. 双击 QuickStart-NetDeploy.bat。面板已运行时直接打开网页，停止后双击则检查更新并在后台启动。
  3. 若提示 8787 已被占用，先到旧的 PowerShell 服务窗口按 Ctrl+C 停止，再重新启动；不要用两个进程同时操作同一数据库。

更新软件，不丢原有数据

推荐先停止旧服务，再双击 QuickStart-NetDeploy.bat；也可运行 Update-NetDeploy.bat 更新后用 Start-NetDeploy.bat 启动。更新器会保留原有的本地配置、任务数据库、可信 SSH 主机密钥，并对本地数据执行备份。

更新后在浏览器按 Ctrl+F5 强制刷新。右上角版本号与 /api/health 返回的版本应一致；否则可能仍在运行旧进程。

Docker / NAS 用户

适合熟悉 Docker 的用户。需要 Docker Engine、Docker Compose v2 和可以写入数据目录的权限。管理页面默认仅映射到宿主机 127.0.0.1:8787，不要直接映射到公网。

  1. 下载项目并准备本地配置：
git clone https://github.com/slobys/netdeploy-ai.git
cd netdeploy-ai
mkdir -p data secrets
cp .env.example .env

编辑 .env，把 NETDEPLOY_ADMIN_TOKEN 和 NETDEPLOY_WORKER_TOKEN 的示例占位值分别改成两段不同的强随机令牌。可执行 openssl rand -hex 32 两次来生成，不要把令牌提交到 GitHub。

# 容器使用 UID 10001 写入 data 目录
sudo chown -R 10001:10001 data
sudo docker compose up -d --build

从另一台电脑访问 NAS 上的面板时，建议先建立 SSH 隧道：

ssh -L 8787:127.0.0.1:8787 YOUR_USER@YOUR_NAS_IP

然后在本机浏览器打开 http://127.0.0.1:8787，使用 .env 中的管理员令牌登录。Docker / NAS 模式不启用 Windows 本地自动登录。需要 SSH 私钥登录 VPS 时，使用专用私钥并按 Compose 配置 提供只读密钥；密码登录不需要设置私钥文件。
