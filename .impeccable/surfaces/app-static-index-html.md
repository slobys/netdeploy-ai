# 部署控制台

## Mode

Operate

## Direction contract

THESIS — 首页先让管理员选择可部署的项目。服务器与任务概况放在项目目录之后。

OWN-WORLD — 雾蓝灰浅色与石墨蓝深色。分区以细线区隔，主题色表示可操作、选中与焦点。SSH 地址使用等宽数字。

STORY — 选项目、确认 VPS、审核方案。也可从相邻的 Codex 入口发出指令。

FIRST VIEWPORT — 左侧导航和紧凑工具栏，右侧先看到项目目录。桌面三列，项目名称、适用范围和动作对齐。窄屏项目按单列展开。部署审批保留独立弹窗。

FORM — 用户选定项目部署优先，直接采用此布局方向。项目目录的操作区沿同一基线排列，安装状态和操作可以逐项扫读。

FINISH — unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
